## Python

### `global` & `nonlocal`

- The `global` and `nonlocal` keywords allow you to modify variables that belong to outer scopes from within a local function scope.

| Feature          | `global`                                           | `nonlocal`                                                                              |
| :--------------- | :------------------------------------------------- | :-------------------------------------------------------------------------------------- |
| **Target Scope** | Outermost module level                             | Nearest enclosing function level                                                        |
| **Strictness**   | Creates a new global variable if one doesn't exist | **Fails with a SyntaxError** if the variable doesn't already exist in an outer function |
| **Common Use**   | Script-wide configuration or state flags           | Closures, function factories, and decorators                                            |

### `global` Keyword

- Used inside a function to **declare that a variable belongs to the outermost (module-level) scope**. Without it, assigning a value to a variable inside a function creates a new local variable.

* **Use Case**: when a function needs to create or modify a variable at the top-level of the script.
* **Scope Level**: connects a local scope directly to the global (module) scope.

```python
x = 10  # Global variable

def modify_global():
    global x
    x = 20  # Modifies the global variable x

modify_global()
print(x)  # Outputs: 20
```

### `nonlocal` Keyword

- Used in nested functions to **declare that a variable belongs to an enclosing (parent) function's scope**, excluding the global scope.

* **Use Case**: closures, decorators, or maintaining state within nested helper functions.
* **Scope Level**: connects an inner local scope to an outer local (enclosing) scope. It will error out if the variable is not found in an outer function (i.e., it cannot skip straight to global).

```python
def outer_function():
    y = "original"  # Enclosing variable

    def inner_function():
        nonlocal y
        y = "modified"  # Modifies outer_function's y

    inner_function()
    print(y)  # Outputs: modified

outer_function()
```
