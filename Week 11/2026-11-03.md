- **N+1 query problem**:
  - Occurs when 1 initial database query fetches a list of parent records, followed by N separate subsequent queries to load related child data for each record.
  - Results in N + 1 total database round-trips—such as fetching 100 posts and then running 100 individual queries for their authors—which severely degrades performance as data scales.
  - It can be fixed by using eager loading or by using joins.
