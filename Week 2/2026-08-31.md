## Java

- Object oriented, statically typed, automatic memory management (w/ garbage collection).
- Created by **Sun Microsystems** in the 90s; now maintained by **Oracle**.
- Write once, run anywhere:
  - Java source code → Java compiler → Bytecode → JVM → OS
- **JDK**: tools needed to develop Java programs (includes the compiler).
- **JRE**: JVM + libraries needed to run Java applications.
- **JShell**: REPL tool for Java.

```
+---------------------------------------------------------+
| JDK (Java Development Kit)                              |
|  [Development Tools: javac, jdb, jar, javadoc...]       |
|                                                         |
|  +---------------------------------------------------+  |
|  | JRE (Java Runtime Environment)                    |  |
|  |  [Standard Libraries: java.lang, java.util...]    |  |
|  |                                                   |  |
|  |  +---------------------------------------------+  |  |
|  |  | JVM (Java Virtual Machine)                  |  |  |
|  |  |  [Executes bytecode on host hardware]       |  |  |
|  |  +---------------------------------------------+  |  |
|  +---------------------------------------------------+  |
+---------------------------------------------------------+
```

## Variables

- Cannot start with a number or contain dashes.
- Primitives: `byte`, `short` `int`, `long`, `float`, `double`, `char`, `boolean`.
- Reference types aren’t the underlying data value, they represent a memory pointer to the value.
- Final variables can be declared first and initialized later but can't be changed after that.
- `System.err`.
