## Java

- Since Strings are immutable, a new String object is created under-the-hood every time.
- Strings are placed in a String Pool, a special place in memory
- The JVM can check the String Pool and reuse similar strings if it makes sense to do so.
- Repeated String concatenation is expensive, so use `StringBuilder` instead.
- There's also `StringBuffer`, which is basically a thread-safe version of `StringBuilder`.
