# 2026-09-02

- Classes & objects.
- A method signature has: an access modifier, static keyword (optional), a return type, method name, and a list of parameters (optional).
- When a Java program runs, the JVM manages memory in several areas:
  - **Stack** – keeps track of method calls, local variables, reference pointers.
  - **Heap** – stores instantiated objects, arrays, & the String Pool.
- Packages:
  - Packages allow us to organize related classes, interfaces, and more into namespaces.
  - This helps keep our code organized and prevent naming conflicts.
  - We have a default unnamed package, but we should strive to create named packages in fully featured applications.
  - The naming convention for packages is typically a reverse domain.
  - By default, everything in `java.lang` is imported.
- Access modifiers: `public`, `protected`, `default`, `private`.
- `static`.
- `java.util.Scanner`.
- **Type conversion** (widening): the safe, automatic process where the Java compiler converts a smaller data type to a larger one.
- **Type casting** (narrowing): an explicit, manual operation performed by the programmer using parentheses to convert a larger data type to a smaller one (narrowing), which carries a risk of data loss.
