## OOP

- OOP Concepts Acronym: `APIE`:
  - **Abstraction**.
  - **Polymorphism**.
  - **Inheritance**.
  - **Encapsulation**.

## Inheritance

### Single Inheritance

```
+---------------+
|     Super     |  <-- Superclass (Parent/Base)
|---------------|
| + fieldA: int |
| + method1()   |
+---------------+
       ^
       | (extends)
       |
+---------------+
|      Sub      |  <-- Subclass (Child/Derived)
|---------------|
| + fieldB: str |
| + method2()   |
+---------------+
```

### Hierarchical Inheritance

```
            +--------------+
            |    Animal    |
            |--------------|
            | + eat()      |
            | + sleep()    |
            +--------------+
                   ^
       ____________|____________
      |                         |
  (extends)                (extends)
+-----------+            +-----------+
|    Dog    |            |    Cat    |
|-----------|            |-----------|
| + bark()  |            | + meow()  |
+-----------+            +-----------+
```

### Multilevel Inheritance

```
+--------------+
|    Parent    |
|--------------|
| + logicA()   |
+--------------+
        ^
        | (extends)
        |
+--------------+
|    Child     |
|--------------|
| + logicB()   |
+--------------+
        ^
        | (extends)
        |
+--------------+
|  Grandchild  |
|--------------|
| + logicC()   |
+--------------+
```

### Multiple Inheritance (NOT Support in Java)

```
+-----------------+       +-----------------+
|    Parent A     |       |    Parent B     |
|-----------------|       |-----------------|
| + propertyA     |       | + propertyB     |
| + doSomething() |       | + doSomething() |
+-----------------+       +-----------------+
        ^                         ^
        |                         |
        +----+ (extends both) +---+
              |                |
      +--------------------------------+
      |             Child              |
      |--------------------------------|
      | Inherits both A and B features |
      +--------------------------------+
```
