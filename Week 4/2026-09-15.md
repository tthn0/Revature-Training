## Running Maven in VS Code

VS Code, won't automatically run an app with an interactive console. Workarounds are provided below:

#### Updating User Settings

- Open your `settings.json` and add:

```json
"java.debug.settings.console": "integratedTerminal"
```

#### Running Directly in CLI

```bash
mvn exec:java -Dexec.mainClass="com.example.yourpackage.MainClassName"
```

## Java Database Connectivity

- **JDBC**: Java API that allows connections to different databases, such as PostgreSQL, MySQL, Microsoft SQL, etc. Consists of classes & interfaces that enable the application to access and send requests to the database made by users.
  - **JDBC API**: collection of various classes, methods, and interfaces to communicate with a database, packaged in the `java.sql` & `javax.sql` packages.
  - **JDBC Driver Manager**: a class within the JDBC API that loads database-specific drivers in the Java application to establish a connection with the database by making a call to a specific database to process a user's request.
  - **JDBC Test Suite**: used to test operations performed on the database using the JDBC drivers.
  - **Database Server**: the database server that the JDBC client will communicate with.

## JDBC Interfaces

- **`Driver`**: base interface for every driver class. If you want to create your own driver class, you would implement this interface. Loading a driver class will create an instance of itself and register it with the `DriverManager`.
- **`Statement`**: represents a static SQL statement, allowing you to execute that statement and obtain the results.
- **`PreparedStatement`**: Represents a pre-compiled statement that you can execute multiple times. You can get an object from this interface using the method of the `Connection` interface `prepareStatement()`. It allows you to get and set values for the variables of the prepared statement.
- **`CallableStatement`**: allows for the execution of stored procedures. It returns a single or multiple results and will accept input parameters as well. It is created using the `prepareCall()` method of the `Connection` interface. Like the `PreparedStatement` interface, it provides get and set methods for those variable values to pass input parameters.
- **`Connection`**: represents the connection with a specific database, through which SQL statements are executed. It includes additional transactional methods to handle commits and rollbacks.
- **`ResultSet`**: database result set, a table generated by executing the SQL statements, and provides getter and update methods to retrieve and update its content, respectively.
- **`ResultSetMetaData`**: used to get information about the result set, such as the number of columns, the names of the columns, data types of the columns, etc.

| Method            | SQL                            | Returns               |
| :---------------- | :----------------------------- | :-------------------- |
| `executeQuery()`  | `SELECT`                       | `ResultSet`           |
| `executeUpdate()` | `INSERT`, `UPDATE`, `DELETE`   | `int` (rows affected) |
| `execute()  `     | SQL where result type may vary | `boolean`             |

## ResultSet Methods

- `next()`: moves the cursor to the next row in the result set and returns true if a valid row exists. This method is typically used in a loop to iterate through all rows.
- `previous()`: moves the cursor to the previous row in the result set and returns true if a valid row exists.
- `first()`: moves the cursor to the first row in the result set and returns true if a valid row exists.
- `last()`: moves the cursor to the last row in the result set and returns true if a valid row exists.
- `absolute(int row)`: moves the cursor to the specified row number, where the first row is 1. Returns true if the specified row is valid.
- `relative(int rows)`: moves the cursor forward or backward by the specified number of rows. The argument can be positive or negative, indicating the direction and magnitude of movement.
- `isFirst()`: returns true if the cursor is currently positioned at the first row in the result set.
- `isLast()`: returns true if the cursor is currently positioned at the last row in the result set.

## Callable Statement w/ In & Out Parameters

```java
CallableStatement statement = connection.prepareCall("{call calculate_gpa(?, ?)}");
statement.setInt(1, 42);
statement.registerOutParameter(2, Types.DOUBLE);
statement.execute();
double gpa = statement.getDouble(2);
```
