## HTML

- **Meta elements** describe the page metadata and help search optimization.
  - Setting the width of the content to the device viewport width is key to rendering content in a consistent way.
- **Semantic elements**: clearly describe their meaning and role in the structure of a webpage.
  - Good for SEO, accessibility, and used by screen readers.
- When the browser loads a page, it first looks to HTML to render the structure of the page, and a DOM is created.
- **Document Object Model** (DOM): represents a web page as a tree of objects, allowing CSS & JavaScript to access, manipulate, and modify the content and styling
  CSS rules are applied to nodes within the DOM.

## CSS

- **Box Model**: responsible for controlling the spacing between elements and their neighboring elements.
  - **Margin**: the space between an element and other elements on the page.
  - **Border**: a perimeter around content which can be customized.
  - **Padding**: the space between the content of an element and the border.
  - **Content**: The actual content of the element - could be text, another element, etc.
- **Position**: determines how an element is positioned in the document and how it behaves relative to other elements.
  - **Static**: default position for all elements; Elements flow naturally.
  - **Relative**: shifted relative to normal position with the top, left, right, and bottom properties.
  - **Absolute**: relative to its parent with the top, left, right, and bottom properties.
  - **Fixed**: relative to the viewport; stays in place when scrolling.
  - **Sticky**: relative until a scroll threshold, then it becomes fixed; requires a top, left, right, or bottom value to work.
- **Flexbox**: a layout system designed to make it easier to arrange and align elements inside a container.
  - Controls how items grow, shrink, and align within a parent container.
  - **Flex container**: where we apply (`{ display: flex; }`).
  - **Flex items**: the child elements inside the flex container.
  - **`justify-content`**: used to align items on the main axis.
  - **`align-items`**: used to align items on the cross axis.
- **Media queries**: lets us apply different styles depending on the host device's characteristics, such as screen size, resolution, or orientation.
  - Used to make site more responsive.

## CSS Specificity

| Selector | Specificity Level |
| :------- | :---------------- |
| ID       | **High**          |
| Class    | **Medium**        |
| Element  | **Low**           |

| Source Type                            | Specificity Level      | Behavior & Rules                                                                                                                                  |
| :------------------------------------- | :--------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Inline Styles**<br>`style="..."`     | **Highest**            | Automatically overrides any conflicting rules written in internal or external stylesheets, regardless of the selectors used.                      |
| **Internal CSS**<br>`<style>` tags     | **Selector Dependent** | Does not inherently outrank external CSS. It competes directly with external CSS based on **selector weight** (IDs > Classes > Elements).         |
| **External CSS**<br>Linked `.css` file | **Selector Dependent** | Does not inherently rank lower than internal CSS. It competes directly with internal CSS based on **selector weight** (IDs > Classes > Elements). |
