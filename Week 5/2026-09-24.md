# 2026-09-23

## TypeScript (TS)

- Made by Microsoft.
- Makes larger apps scale easier.
- Gives our linters warnings when we make typos or use incorrect types.
- Compile TS to JS:
  - `tsc app.ts`.
  - TypeScript officially calls the conversion "compilation".
  - Technically, it's actually "transpilation".
- Build included files in `src` via `tsconfig`:
  - `tsc --build src`.
- Generate `tsconfig.json` file (compiler settings):
  - `tsc --init`.

## Definition Files

- `.d.ts` file extension.
- Contains no runtime code, only definitions for types used elsewhere.

## Syntax Details

- We typically use interfaces over classes when defining new types because interfaces define only a contract and will not generate any runtime code like a class would.
- We can mark a field as nullable with `?` when defining interfaces.
- The `readonly` keyword may be used to mark properties as constants.
- Opt for `type` syntax instead of defining an actual `enum`.
  - This generates zero runtime cost (less bundled code after compilation).
- Use `unknown` instead of `any`.
  - It behaves the same, but we must still cast it before using it.
