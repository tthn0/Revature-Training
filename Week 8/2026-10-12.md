## Spring Modules

- Each of these are separate Spring projects or technologies:
  - **Spring MVC**: architecture pattern, server-side rendering.
  - **Swagger**: testing & development module.
  - **Spring for GraphQL**: Spring project for making queries of different shapes of data.
  - **Spring Security**: Spring project for authentication/authorization + RBAC.
  - **Spring AI**: Spring project to connect AI models from providers such as OpenAI, Anthropic, and Ollama using familiar Spring programming patterns.

## MVC

- **Model**: represents application data and business rules.
  - Examples: entities, services, repositories, domain logic.
- **View**: presents information to the user.
  - Examples: HTML templates, JSON consumed by a UI, or a rendered interface.
- **Controller**: handles input, coordinates application operations, and determines the response.
  - Examples: Spring `@Controller` or `@RestController`.
- Implementations:
  - Spring Boot app that returns JSON + React/Angular.
  - Spring Boot MVC + Thymeleaf.
  - BOTH follow a MVC pattern .

## Swagger

- Swagger is a set of tools and conventions for describing, documenting, and testing REST APIs.
- In a Spring Boot app, exposes your API endpoints in an interactive webpage so developers can understand your API and try requests without needing Postman or writing a client first.

| Annotation     | Purpose                                                    |
| :------------- | :--------------------------------------------------------- |
| `@Tag`         | Groups related endpoints under a named section.            |
| `@Operation`   | Provides a summary and detailed endpoint description.      |
| `@ApiResponse` | Documents possible HTTP responses.                         |
| `@Parameter`   | Describes a path, query, or other parameter.               |
| `@Schema`      | Documents a DTO's fields, constraints, and example values. |

### Swagger Annotation Example (Controller)

```java
@GetMapping("/{id}")
@Operation(
    summary = "Get a product",
    description = "Returns a product by its ID"
)
@ApiResponse(
    responseCode = "200",
    description = "Product found"
)
@ApiResponse(
    responseCode = "404",
    description = "Product not found"
)
public ProductDto getProduct(
    @Parameter(description = "Unique product ID")
    @PathVariable Long id
) {
    return productService.getById(id);
}
```

### Swagger Annotation Example (DTO)

```java
import io.swagger.v3.oas.annotations.media.Schema;
```

## REST vs GraphQL

- **REST** typically exposes multiple endpoints.
- **GraphQL** is an API query language and runtime that lets clients request exactly the data they need.
  - Allows for building APIs that are flexible, strongly typed, and easy to scale.
  - Typically exposes one endpoint where you can request different shapes of data.

## GraphQL

| Syntax          | Meaning                                       |
| --------------- | --------------------------------------------- |
| `type Customer` | Defines an object type                        |
| `type Query`    | Defines read operations                       |
| `type Mutation` | Defines write operations                      |
| `ID`            | Represents an identifier                      |
| `String`        | Represents text                               |
| `!`             | The value cannot be null                      |
| `[Customer!]!`  | A non-null list containing non-null customers |

## Annotations

- `@Controller`: registers the Spring controller.
- `@QueryMapping`: maps a Java method to a field under the schema's Query type.
- `@MutationMapping`: maps a Java method to a field under the schema's Mutation type.
- `@Argument`: binds a GraphQL argument to a Java method parameter.

```java
@Controller
public class CustomerGraphQLController {
  @QueryMapping
  public List<Customer> customers() {
    return List.of(
      new Customer(1L, "Alice", "alice@example.com"),
      new Customer(2L, "Bob", "bob@example.com")
    );
  }

  @QueryMapping
  public Customer customerById(@Argument Long id) {
    return new Customer(id, "Alice", "alice@example.com");
  }

  @MutationMapping
  public Customer createCustomer(
    @Argument String name,
    @Argument String email) {
   return new Customer(3L, name, email);
  }
}
```
