# 2026-10-13

- **Microservices Architecture** (MSA) concepts:
  - **API gateway**: acts as a single entry point for all client requests, handling cross-cutting concerns like routing, authentication, and rate limiting before forwarding traffic to internal microservices.
  - **Circuit breaker**: a fault-tolerance pattern that monitors remote service calls, automatically tripping to fail fast when downstream failures spike so the system can degrade gracefully and recover without cascading bottlenecks.
    - **Closed**: requests flow freely to the downstream service while the circuit breaker monitors error rates against a pre-configured failure threshold.
    - **Open**: the circuit breaker immediately fails fast and blocks all outgoing requests without attempting to call the unhealthy downstream service.
    - **Half-Open**: a limited number of test requests are permitted through to check if the underlying issue has been resolved, closing the circuit if they succeed or reopening it if they fail.
- Technologies:
  - **Spring Cloud Config Server**: provides centralized, externalized configuration management for a distributed system, allowing microservices to pull environment-specific properties from a unified repository (such as Git).
  - **Feign Client**: a declarative REST client that simplifies HTTP communication between microservices by enabling developers to invoke remote services using annotated Java interfaces.
  - **Consul Agent**: a service networking tool that handles distributed service discovery, real-time health checking, and key-value configuration storage across a microservices cluster.
  - **Netflix Eureka**: a service registry from Netflix OSS that allows microservices to dynamically register themselves upon startup and discover the network locations of other services without hardcoding IP addresses.
